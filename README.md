
# Fathur Rahman — Portofolio Pribadi

Website portofolio pribadi yang menampilkan profil, keterampilan teknis, proyek, sertifikat, dan pengalaman di bidang Data Analytics, Data Engineering, serta teknologi.

## Tentang

Saya adalah mahasiswa S1 Teknologi Informasi Universitas Muhammadiyah Yogyakarta yang memiliki ketertarikan pada bidang Data Analytics dan Data Engineering. Website ini dibuat sebagai media untuk menampilkan keterampilan teknis, proyek yang telah dikerjakan, serta perjalanan belajar saya di bidang teknologi dan data.

## Teknologi yang Digunakan

- HTML5
- CSS3
- JavaScript
- Tailwind CSS

## Fitur Website

- Profil dan informasi pribadi
- Informasi pendidikan
- Daftar keterampilan teknis
- Galeri proyek dan detail proyek
- Daftar sertifikat
- Testimoni
- Informasi kontak dan media sosial
- Tombol unduh CV
- Desain responsif untuk desktop dan perangkat mobile
- Animasi dan interaksi website

## Cara Menjalankan Website

1. Clone repository:

   ```bash
   git clone https://github.com/FathurRahman0/fathur-rahman-portfolio.git
   ```
2. Buka folder project menggunakan Visual Studio Code.
3. Install ekstensi **Live Server** jika belum tersedia.
4. Klik kanan file `index.html`.
5. Pilih **Open with Live Server** untuk menjalankan website melalui browser.
